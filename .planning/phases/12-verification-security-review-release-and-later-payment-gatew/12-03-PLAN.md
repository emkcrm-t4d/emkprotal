       - Add `<a href="#main-content" class="sr-only focus:not-sr-only focus:absolute focus:p-4 focus:bg-indigo-600 focus:text-white focus:z-50">Skip to main content</a>` skip-navigation link.
       - Ensure standard landmark roles: `<header role="banner">`, `<main id="main-content" role="main">`, `<nav aria-label="...">`, `<footer role="contentinfo">`.

       - Status badges (Active, Expired, Pending) must use accessible contrast colors and aria labels.
       - Password reset inputs must have explicit labels, autocomplete hints (`autocomplete="new-password"`), and aria descriptions for password complexity rules.

       - Assert skip link exists and points to `#main-content`.

       - Assert error summaries and live regions carry `aria-live="polite"`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Browser Viewport → Public Form Layout | Untrusted client device rendering responsive markup and executing client scripts |
| Assistive Technology → Rendered DOM | Screen readers and assistive tools consuming accessibility tree and ARIA roles |
| Public User → Modal Dialogs & Menus | Keyboard / touch inputs interacting with mobile navigation drawers and modals |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-11 | Denial of Service | Mobile Viewport Layout | medium | mitigate | Enforce responsive overflow handling (`overflow-x-auto` on tables, flex/grid wrapping) to prevent UI breakage or unusable inputs on 320px screens |
| T-12-12 | Information Disclosure | Error Summaries / Live Regions | low | mitigate | Ensure ARIA live regions announce validation summaries without echoing sensitive credentials or system stack traces |
| T-12-13 | Tampering | Client-side Age Calculation Script | medium | mitigate | Maintain redundant server-side date of birth and age calculation in `LeadIngestionService`; client Alpine.js age is strictly for assistive UI feedback |
| T-12-14 | Repudiation | Form Submission Accessibility | low | mitigate | Ensure disabled submit buttons have descriptive `aria-disabled` and clear visual feedback preventing confusing repeated submissions |
| T-12-15 | Elevation of Privilege | Mobile Navigation Drawer | low | mitigate | Render navigation items conditionally based on server-authenticated permissions; mobile drawer does not expose unauthenticated admin links |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate + blocking human checkpoint for any unverified external packages; zero new dependencies introduced |
</threat_model>
