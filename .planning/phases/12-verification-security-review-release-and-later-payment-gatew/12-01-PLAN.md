<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public Applicant / Member → Payment Gateway | Untrusted client initiates payment or submits payment confirmation data |
| External Gateway Webhook → Hub Webhook Endpoint | External server callback carrying transaction settlement notifications |
| Staff Manager → Manual Payment Verification | Authenticated staff user verifies 10-character bKash TxID against bank records |
| Payment Driver Configuration → Secret Storage | Environment credentials (gateway keys/secrets) read from .env, never hard-coded |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | PaymentAdapterInterface / DTOs | high | mitigate | Encapsulate request and result payloads in readonly immutable PHP 8.2 DTOs; validate all parameters prior to adapter dispatch |
| T-12-02 | Spoofing | Webhook callback handler | high | mitigate | Enforce digital signature verification (HMAC-SHA256 / IPN token validation) before processing any webhook callback in Mock/Gateway adapters |
| T-12-03 | Elevation of Privilege | ManualBkashPaymentAdapter | critical | mitigate | Throw UnsupportedPaymentOperationException if online checkout or webhook actions are attempted on the manual driver, preventing unverified automated state changes per DEC-05 |
| T-12-04 | Information Disclosure | config/payments.php | high | mitigate | Read all gateway credentials from environment variables (`env()`); forbid storing raw API keys, passwords, or secrets in version-controlled config files |
| T-12-05 | Denial of Service | PaymentManager driver resolution | medium | mitigate | Enforce strict driver validation in `PaymentManager::driver()`; throw `InvalidArgumentException` for unknown drivers rather than crashing or returning null |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate + blocking human checkpoint for any unverified external packages; zero new composer/npm packages introduced in this plan |
</threat_model>
