<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Livewire Client Payload → Server Hydration | Untrusted HTTP POST payload sent by client containing component state and model IDs |
| Public File Upload → Server File Storage | Untrusted binary data uploaded by applicants during registration |
| User Browser → Document Download Endpoint | Authenticated request requesting private applicant identity scans and photos |
| CSV Export Service → User Spreadsheet Application | Exported member data opened in Microsoft Excel or Google Sheets |
| Eloquent Queries → Database Table Permissions | Application database interactions with append-only audit_logs table |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-06 | Tampering | Livewire Component Hydration | critical | mitigate | Enforce `ValidatesWorkspaceOnHydration` on all workspace Livewire components; verify tenant ownership of every hydrated model before executing actions |
| T-12-07 | Information Disclosure | CRM Model Endpoints (IDOR) | critical | mitigate | Apply Eloquent global scope (`BelongsToTenant`) and explicit policy authorization on every record lookup; reject cross-workspace access with 403 |
| T-12-08 | Elevation of Privilege | File Upload Pipeline | high | mitigate | Verify MIME type and magic bytes server-side; strip EXIF data; store files outside web root on private disk; forbid direct script execution |
| T-12-09 | Tampering | DocumentDownloadController | high | mitigate | Sanitize file paths using `basename()` and storage abstraction; strictly prohibit directory traversal characters (`..`, `%2e%2e`) |
| T-12-10 | Tampering | CsvExportService | medium | mitigate | Sanitize cell values beginning with `=`, `+`, `-`, `@`, `\t`, `\r` by prefixing a single apostrophe to prevent DDE code execution in spreadsheets |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate + blocking human checkpoint for any unverified external packages; zero new dependencies added |
</threat_model>
