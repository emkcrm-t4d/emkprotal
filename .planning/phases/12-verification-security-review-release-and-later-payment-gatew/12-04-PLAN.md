       - `checkRedis(): array`: verifies Redis client connection ping response (`PONG`).
       - `checkQueues(): array`: verifies configured Horizon queues (`high_priority`, `emails`, `documents`, `default`) and checks for failed job accumulation.

       - Signature: `crm:system:health-check {--json : Output report in JSON format}`.
       - Description: `Run comprehensive production environment and worker health diagnostics.`

       - Returns exit code 0 if all checks pass or only non-critical warnings exist; returns exit code 1 if any critical checks fail.
       - In JSON mode (`--json`), outputs raw JSON with timestamp, overall status, and component metrics.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server Shell / CLI → Artisan Commands | Privileged administrator executing maintenance and provisioning commands |
| Production Health Checker → Infrastructure Services | Automated health check probes connecting to MySQL, Redis, and filesystem |
| Admin Provisioning Tool → User Credentials & Roles | Command creating Superadmin accounts with unlimited system access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-16 | Elevation of Privilege | ProvisionAdminCommand | critical | mitigate | Enforce 12+ character complexity; restrict command execution to server console; record immutable audit trail on every execution per DEC-11 |
| T-12-17 | Information Disclosure | SystemHealthCheckCommand | medium | mitigate | Mask sensitive connection strings and passwords in health check output and JSON telemetry; display only status indicators and error categories |
| T-12-18 | Tampering | Production .env Configuration | critical | mitigate | Set strict file permissions (chmod 600) on `.env`; verify `APP_DEBUG=false` in health check; document secret rotation in runbook |
| T-12-19 | Denial of Service | Queue Worker Stoppage | high | mitigate | Provide systemd supervisor configuration with auto-restart (`Restart=always`); health checker alerts when Horizon workers are inactive |
| T-12-20 | Repudiation | CLI Admin Password Changes | high | mitigate | Emit `admin_provisioned` / `password_rotated` events into append-only `audit_logs` capturing target email, role, and execution timestamp |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate + blocking human checkpoint for any unverified external packages; zero external packages installed |
</threat_model>
