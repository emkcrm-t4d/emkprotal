## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File System → Ingestion Parser | Untrusted legacy CSV files cross the system execution boundary |
| Staging Record → Domain Model | Raw unvalidated legacy payloads cross into core database entities |
| CLI Invocation → Database Transaction | Operator console parameters dictate tenant workspace routing |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Tampering | ZohoFieldMappingService | high | mitigate | Sanitize all incoming strings, enforce strict date formatting, validate enum values, and reject unexpected script tags or SQL injection payloads in CSV cells |
| T-11-02 | Denial of Service | ZohoDataIngestionService | high | mitigate | Process CSV via streaming generator in chunks (default 100 rows) with gc_collect_cycles() to guarantee memory consumption stays under 64MB |
| T-11-03 | Elevation of Privilege | ZohoImportCommand | medium | mitigate | Enforce workspace existence validation against workspaces table; reject arbitrary or cross-tenant workspace parameters |
| T-11-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package legitimacy gate + blocking human checkpoint for assumed/sus packages |
</threat_model>
