  <action>
    Implement `App\Domain\Migration\Services\ZohoAttachmentMigrationService` to process legacy attachments per MIGR-03, ARCH-06, and DEC-09:
    1. Input validation & path traversal defense:
       - Validate that the source directory exists and is readable.
       - Method `sanitizeRelativePath(string $baseDir, string $relativePath): string`. Reject path traversal indicators (`..`, `./`, leading slashes, null bytes `%00`). Verify resolved path via `realpath()` starts strictly within `$baseDir`. Throw `SecurityException` if boundary is violated.
       - Validate file extensions and MIME types: allow strictly `image/jpeg`, `image/png`, `application/pdf`. Prohibit dangerous extensions (`.php`, `.phtml`, `.exe`, `.sh`, `.blade.php`).
       - Validate magic bytes: check file headers to prevent extension spoofing.
    2. File processing and privacy safeguards:
       - Strip EXIF metadata from studio photos and JPEG scans to eliminate GPS coordinates and device identifiers.
       - Compute SHA-256 hash of raw binary content prior to encryption.
       - Encrypt file payload using AES-256 via `DocumentStorageService::store()` on the private storage disk (`storage/app/private`).
       - Generate UUID v4 for physical storage filename (`{uuid}.dat` or `{uuid}.{ext}`). Client original filename preserved strictly in `lead_attachments.original_filename`.
       - Check applicant age: if age < 18 or document type is `parental_consent`, set `youth_protection = true` per DEC-09.
    3. Model linking:
       - Method `migrateAttachment(string $sourceFilePath, string $zohoId, string $documentType, string $workspaceId): LeadAttachment`.
       - Lookup target entity via `zoho_id`: check `members` first, then `leads`. If member found, retrieve associated lead record (`$member->lead_id`).
       - Create record in `lead_attachments` table with `workspace_id`, `lead_id`, `document_type`, `storage_path`, `original_filename`, `mime_type`, `size_bytes`, `file_hash`, `youth_protection`.
       - Write immutable audit event in `audit_logs` (`event_type = 'zoho_attachment_migrated'`).
    4. Author `tests/Feature/ZohoAttachmentMigrationTest.php`:
       - Test valid attachment migration for identity documents and studio photos.
       - Test that files are stored encrypted on the `private` disk and cannot be read as plain text directly from disk.
       - Test that path traversal attacks (`../../etc/passwd` or `..\\windows\\win.ini`) are trapped and rejected.
       - Test that executable file uploads (.php, .exe) are rejected with security exceptions.
       - Test that youth protection flag is accurately set for minors.
  </action>
