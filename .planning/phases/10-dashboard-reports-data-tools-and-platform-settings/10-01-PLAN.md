       - Define typed readonly properties:
         - `public int $totalMembers`
         - `public array $memberStatusBreakdown` (keys: active, inactive, restricted, revoked, archived_reversed)
         - `public int $totalLeads`
         - `public array $leadPipelineBreakdown` (keys: draft, submitted, under_review, missing_items, approved, converted, rejected, blocked)

         - `public int $totalIdCards`
         - `public array $idCardStatusBreakdown` (keys: provided_for_printing, card_printed_ready_for_pickup, delivered, superseded_replaced, voided_reversal)
         - `public float $totalRevenueBdt` (sum of paid invoices in BDT)
         - `public int $paidInvoicesCount`
         - `public ?string $workspaceId`
         - `public ?string $dateFrom`
         - `public ?string $dateTo`
       - Include helper methods: `toArray(): array`.
    2. Create Service `app/Domain/Reports/Services/MetricsAggregationService.php`:
       - Method: `public function getMetrics(string $workspaceId, ?string $dateFrom = null, ?string $dateTo = null, bool $useCache = true): OperationalMetricsDTO`.
       - Query aggregation strategy:
         - Execute database-level aggregates via `selectRaw('status, count(*) as count')->groupBy('status')` across `Member`, `Lead`, `IdCard`, and `Invoice`.
         - Scope queries strictly to `$workspaceId` using `where('workspace_id', $workspaceId)`.
         - Apply optional date range filters on `created_at` or `submitted_at` or `paid_at` within `[$dateFrom, $dateTo]`.
         - Compute `conversionRate`: `floatval($totalLeads > 0 ? round(($convertedCount / $totalLeads) * 100, 2) : 0.0)`.
         - Compute `totalRevenueBdt`: `Invoice::where('workspace_id', $workspaceId)->where('status', 'paid')->sum('amount_bdt')`.
       - Performance caching:
         - Generate deterministic cache key: `metrics_{$workspaceId}_{$dateFrom}_{$dateTo}`.
         - Cache result for 300 seconds (5 minutes) using `Cache::remember`.
         - Provide `clearMetricsCache(string $workspaceId): void`.
    3. Create Livewire Component `app/Livewire/Reports/OperationalDashboard.php`:
       - Properties:
         - `public string $workspaceId`
         - `public string $datePreset = '30_days'` ('7_days', '30_days', '90_days', 'year', 'all', 'custom')
         - `public ?string $dateFrom = null`
         - `public ?string $dateTo = null`
       - Authorization check in `mount`: verify user belongs to workspace or is superadmin/global_admin, and possesses permission `dashboard_reports.view_dashboard`.
       - Method `applyDatePreset(string $preset)`: sets `dateFrom` and `dateTo` based on Carbon presets:

         - `30_days`: `now()->subDays(30)->toDateString()` to `now()->toDateString()`.
         - `90_days`: `now()->subDays(90)->toDateString()` to `now()->toDateString()`.
         - `year`: `now()->startOfYear()->toDateString()` to `now()->toDateString()`.
         - `all`: `dateFrom = null`, `dateTo = null`.
       - Method `refreshMetrics()`: invokes `MetricsAggregationService->clearMetricsCache($this->workspaceId)` and recomputes.
       - Method `render()`: resolves `MetricsAggregationService`, passes `OperationalMetricsDTO` to view.
    4. Create Blade View `resources/views/livewire/reports/operational-dashboard.blade.php`:

       - ID Card Printing & Delivery lifecycle status breakdown.
       - Date filter controls with preset buttons and custom date inputs.

       - Verify metrics caching caches results and refresh button clears cache.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staff User → Dashboard Query | Untrusted date filters and workspace identifiers cross HTTP request boundary |
| Tenant Boundary → Multi-Workspace Scope | Non-superadmin staff must never observe metrics from another American Space |
| Aggregation Service → Database Query | Unbounded queries on large datasets must not exhaust server memory or CPU |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Information Disclosure | OperationalDashboard Livewire | high | mitigate | Enforce workspace tenancy via VerifyWorkspaceAccess middleware and TenantScope, strictly prohibiting cross-workspace inspection for non-superadmins. |
| T-10-02 | Denial of Service | MetricsAggregationService | medium | mitigate | Enforce 5-minute query caching by workspace and date range, utilize database-level count/sum aggregates, and cap date ranges. |
| T-10-03 | Elevation of Privilege | OperationalDashboard Livewire | high | mitigate | Restrict global multi-workspace toggle visibility and backend execution strictly to users with superadmin or global_admin roles. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | package-legitimacy gate + blocking human checkpoint for assumed/sus packages. |
</threat_model>
