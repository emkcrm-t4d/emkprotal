           - Returns associative array of key => cast value for a group, with workspace overrides applied.
         - `public function seedDefaults(): void`:

             - `general.contact_email`: 'info@emkcenter.org'
             - `membership.default_term_code`: 'STANDARD_1YR'

             - `security.require_password_reset_days`: 90

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staff User → Settings Mutation | System parameters control critical business logic, fees, and security timeouts |
| Parameter Storage → Presentation View | Secret credentials must not be rendered in plain text HTML or JavaScript |
| Audit Trail → Secret Scrubbing | Audit logs must never store plaintext passwords, tokens, or encryption keys |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-07 | Elevation of Privilege | PlatformSettingsHub Livewire | high | mitigate | Restrict all platform settings endpoints to users possessing the non-delegable 'platform_services.manage_settings' permission; reject delegated staff with HTTP 403. |
| T-10-08 | Information Disclosure | PlatformSetting Model & Views | high | mitigate | Encrypt sensitive parameters at rest using AES-256 (cast_type: encrypted), mask values as '••••••••' in presentation views, and redact secrets in audit trail logs per ASVS V8.2 and DEC-11. |
| T-10-09 | Tampering | PlatformSettingsService | medium | mitigate | Enforce strict validation rules and type casting on system parameters before database persistence to prevent service corruption. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | package-legitimacy gate + blocking human checkpoint for assumed/sus packages. |
</threat_model>
