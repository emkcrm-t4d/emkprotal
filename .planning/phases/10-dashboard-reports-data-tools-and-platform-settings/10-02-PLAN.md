    1. Create Service `app/Domain/Reports/Services/WorkspaceDataExportService.php`:
       - Methods:
         - `public function exportMembers(string $workspaceId, array $filters = [], string $format = 'csv'): \Symfony\Component\HttpFoundation\StreamedResponse`
         - `public function exportLeads(string $workspaceId, array $filters = [], string $format = 'csv'): \Symfony\Component\HttpFoundation\StreamedResponse`
         - `public function exportInvoices(string $workspaceId, array $filters = [], string $format = 'csv'): \Symfony\Component\HttpFoundation\StreamedResponse`
         - `public function exportMetrics(string $workspaceId, array $filters = []): \Symfony\Component\HttpFoundation\StreamedResponse`
       - Workspace Authorization Guard:
         - Resolve authenticated user via `Auth::user()`. If unauthenticated, abort 401.
         - Check if user is Superadmin (`hasRole(['superadmin', 'global_admin'])`). If not superadmin, enforce `(string) $user->workspace_id === $workspaceId`. If mismatch, abort 403 with 'Unauthorized workspace access.'.
       - Memory Exhaustion Defense (T-10-05):
         - Execute query with chunking (`$query->chunk(200, function ($records) use ($handle) { ... })`) or lazy cursor, writing rows incrementally to `php://output`.
         - Stream response using `Symfony\Component\HttpFoundation\StreamedResponse` with headers:
           - `'Content-Type' => 'text/csv; charset=UTF-8'`
           - `'Content-Disposition' => "attachment; filename=\"{$filename}\""`
           - `'Cache-Control' => 'no-cache, no-store, must-revalidate'`
         - Prepend UTF-8 Byte Order Mark (`\xEF\xBB\xBF`) for clean UTF-8 encoding in Microsoft Excel.
       - Formula Injection Sanitization (T-10-04):
         - Method `public function sanitizeCsvCell(mixed $value): string`:
           - If value is null, return empty string `''`.
           - Convert booleans to `'Yes'` / `'No'`.
           - Cast to string, trim whitespace.
           - If first character is `=`, `+`, `-`, or `@`, prepend single quote: `return "'" . $str;`.
       - Columns exported for Members:
         - `Member ID`, `Status`, `First Name`, `Last Name`, `Email`, `Contact Number`, `Date of Birth`, `Gender`, `Division`, `District`, `Occupation`, `Institution`, `Start Date`, `Expiry Date`, `Created At`.
       - Columns exported for Invoices:
         - `Invoice Number`, `Member ID`, `Amount (BDT)`, `Payment Method`, `Payment Reference`, `Status`, `Paid At`, `Created At`.
       - Columns exported for Leads:
         - `Lead ID`, `Status`, `First Name`, `Last Name`, `Email`, `Contact Number`, `Target Space`, `bKash TxID`, `Submitted At`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Export Request → Server Query | Untrusted export query filters cross HTTP boundary |
| Server File Generation → Client Spreadsheet | Dynamic member/lead data rendered in CSV/Excel could exploit spreadsheet parser |
| Data Exfiltration → Audit Trail | Bulk data downloads must be permanently recorded to prevent unmonitored exfiltration |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-04 | Remote Code Execution | WorkspaceDataExportService | high | mitigate | Prepend single quote (') to all exported CSV and spreadsheet cells beginning with '=', '+', '-', or '@' to neutralize command execution in spreadsheet readers. |
| T-10-05 | Denial of Service | WorkspaceDataExportService | medium | mitigate | Stream export responses using Symfony StreamedResponse chunking records by 200, avoiding hydration of entire datasets into server memory. |
| T-10-06 | Repudiation | WorkspaceExportController | high | mitigate | Record immutable audit log entries in audit_logs capturing actor_id, workspace_id, row count, filters, and filename upon every export initiation per DEC-11. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | package-legitimacy gate + blocking human checkpoint for assumed/sus packages. |
</threat_model>
