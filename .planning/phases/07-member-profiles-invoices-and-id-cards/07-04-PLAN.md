| Front Desk Browser -> ID Card Operations | Authenticated staff requesting ID card queues and performing batch operations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-10 | Elevation of Privilege | `IdCardDirectory::deliverCard` | High | mitigate | Require `can:members.manage_cards` permission and capture delivering staff user ID and collection timestamp in immutable audit logs per DEC-11. |
| T-07-11 | Tampering | `IdCardLifecycleService` State Machine | Medium | mitigate | Enforce strict finite state machine validation, rejecting illegal transitions (e.g. `provided_for_printing` -> `delivered`) with `InvalidCardStateTransitionException`. |
| T-07-12 | Denial of Service / Spam | `IdCardLifecycleService::markPrinted` | Medium | mitigate | Assert card status is strictly `provided_for_printing` before dispatching `CardReadyNotificationMail`, preventing duplicate notification email spamming on repeated updates. |
| T-07-SC | Tampering | npm/pip/cargo installs | High | mitigate | package-legitimacy gate + blocking human checkpoint for [ASSUMED]/[SUS] |
</threat_model>
