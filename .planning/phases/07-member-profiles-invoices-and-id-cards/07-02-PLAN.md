    Implement `MembershipValidityEngine` in `app/Domain/Members/Services/MembershipValidityEngine.php`:
    1. Define class in `App\Domain\Members\Services` namespace.
    2. Implement `calculateInitialDates(MembershipTerm $term, ?\Carbon\CarbonInterface $startDate = null): array`:
       - Default `$startDate` to `now()` (approval timestamp per DEC-08)
       - Calculate `$expiryDate = $startDate->copy()->addMonths((int) $term->duration_months)`
       - Return associative array with `start_date` and `expiry_date` as `CarbonInterface` instances
    3. Implement `calculateRenewalDates(Member $member, MembershipTerm $term, ?\Carbon\CarbonInterface $renewalDate = null): array`:
       - Default `$renewalDate` to `now()`
       - Check if current renewal is an early renewal: `$renewalDate->lte($member->expiry_date)` or within 30-day early renewal window (`isWithinRenewalWindow($member, $renewalDate)`)
       - If early renewal (prior to expiration): append term duration to existing expiration date (`$newExpiryDate = $member->expiry_date->copy()->addMonths((int) $term->duration_months)`), keeping `$member->start_date` unchanged so no days are lost per STATUS-DICTIONARY Section 7.2
       - If late renewal (post-expiration): reset `$newStartDate = $renewalDate` and compute `$newExpiryDate = $newStartDate->copy()->addMonths((int) $term->duration_months)`
       - Return array with `start_date` and `expiry_date`
    4. Implement `isWithinRenewalWindow(Member $member, ?\Carbon\CarbonInterface $checkDate = null): bool`:
       - Default `$checkDate` to `now()`
       - Window opens 30 calendar days prior to `$member->expiry_date`: `$windowStart = $member->expiry_date->copy()->subDays(30)`
       - Return true if `$checkDate->gte($windowStart)`
    5. Implement `isExpired(Member $member, ?\Carbon\CarbonInterface $checkDate = null): bool`:
       - Default `$checkDate` to `now()`
       - Return true if `$member->expiry_date->lt($checkDate)`
    6. Implement unit test `tests/Unit/MembershipValidityEngineTest.php`:
       - Test initial induction calculation with various term durations (6 months, 12 months, 24 months)
       - Test early renewal calculation asserting that remaining days on current membership are preserved and added to the new duration
       - Test late renewal calculation asserting start date resets to renewal approval date
       - Test 30-day renewal window boundaries (31 days prior = false, 30 days prior = true, 1 day prior = true, expired = true)
       - Test expiration detection logic
  </action>
