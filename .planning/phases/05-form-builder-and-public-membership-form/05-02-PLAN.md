  <action>
    Create Livewire components for Form Administration under `app/Livewire/Forms`:
    1. `FormIndex`:
       - Uses `WithPagination` and `ValidatesWorkspaceOnHydration`.
       - Mounted at route `GET /crm/{workspace}/forms` with name `crm.forms.index`.
       - Requires `forms.view` permission; workspace isolation enforced server-side.
       - Lists all forms in current workspace (or all for Superadmin) with title, slug, version, published status, submission count, and action buttons (Builder, Submissions, Embed, Publish/Archive).
       - Provides modal/drawer for creating a new form with Title, Slug, Description, and Workspace assignment (requires `forms.create`).
    2. `FormBuilder`:
       - Uses `ValidatesWorkspaceOnHydration`.
       - Mounted at route `GET /crm/{workspace}/forms/{form}/builder` with name `crm.forms.builder`.
       - Requires `forms.edit` permission.
       - Visual field editor allowing adding, editing, reordering, and deleting fields from `$form->schema`.
       - Supports configuring field label, field key, input type (from `FormSchemaEngine::getFieldCatalog()`), required toggle, help text, placeholder, min/max lengths, regex pattern, and options for select/radio.
       - Supports conditional logic configuration (e.g. show if field X equals Y, require if field A < B).
       - Generates embed code modal offering:
         a) Public permalink (`route('public.forms.show', $form->slug)`).
         b) Responsive iFrame embed snippet (`&lt;iframe src="..." width="100%" height="800" frameborder="0"&gt;&lt;/iframe&gt;`).
         c) HTML/CSS embed snippet for external landing pages.
       - Managerial Actions:
         - `publish()` method requires non-delegable `forms.publish` permission per MODULE-REGISTRY.md. Sets `is_published = true`.
         - `archive()` method requires non-delegable `forms.archive` permission per MODULE-REGISTRY.md. Sets `is_published = false`.
         - Non-managers attempting to invoke publish or archive are rejected with HTTP 403.

    Create Blade views `resources/views/livewire/forms/form-index.blade.php` and `resources/views/livewire/forms/form-builder.blade.php` styled with Tailwind CSS matching the administrative shell (`layouts/admin.blade.php`).

    Register routes in `routes/web.php` inside the `/crm/{workspace}` route group with `workspace.access` middleware:
    - `Route::get('/forms', \App\Livewire\Forms\FormIndex::class)->name('crm.forms.index');`
    - `Route::get('/forms/{form}/builder', \App\Livewire\Forms\FormBuilder::class)->name('crm.forms.builder');`

    Create feature test `tests/Feature/FormBuilderAdminTest.php`:
    - Tests workspace staff with `forms.view` can access FormIndex and see only their workspace forms.
    - Tests staff without `forms.view` receives HTTP 403.
    - Tests creating and updating form field schema through Livewire actions.
    - Tests Workspace Manager can publish and archive forms.
    - Tests delegated staff with `forms.edit` can edit fields but receives HTTP 403 when attempting to call `publish()` or `archive()`.
    - Tests embed options generate correct permalinks and iframe code.
  </action>
