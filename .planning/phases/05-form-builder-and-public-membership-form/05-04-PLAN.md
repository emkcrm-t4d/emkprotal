  <action>
    Create `app/Domain/Forms/Services/DuplicateSubmissionGuard.php` enforcing duplicate prevention rules per FORM-04, FORM-05, and DEC-05 (D-05):
    1. Method `assertUniqueBkashTxid(string $txid): void`:
       - Normalizes TxID to uppercase trimmed string (`Str::upper(trim($txid))`).
       - Validates format matches exactly 10 uppercase alphanumeric characters (`/^[A-Z0-9]{10}$/`).
       - Checks existence in `leads` table across all statuses (submitted, under_review, approved, converted, or rejected).
       - Checks existence in `invoices` table (`payment_reference` column).
       - If a matching TxID exists in either table, throws `ValidationException` with message: "This bKash Transaction ID has already been submitted. If you believe this is an error, please contact EMK Center Information Desk."
    2. Method `assertUniqueEmail(string $email): void`:
       - Normalizes email to lowercase trimmed string.
       - Checks `users` table for existing member portal accounts (`guard = member` or `email = $email`).
       - Checks `leads` table for existing applications with status `submitted`, `under_review`, `approved`, or `converted`.
       - If an existing active/pending record is found, throws `ValidationException` with message: "An application with this email address is already active or registered."
       - Exception rule per LEAD-07 and DEC-01: If an applicant has a previous application with status `rejected`, reapplication is allowed (unless email is explicitly in status `blocked`).
    3. Method `checkRateLimit(string $ipAddress): void`:
       - Utilizes Laravel RateLimiter with key `membership_submit:{$ipAddress}`.
       - Enforces max 10 submissions per minute per IP address per ASVS V5.2 / T-02-09.
       - If exceeded, throws `ThrottleRequestsException` (HTTP 429).

    Create feature test `tests/Feature/DuplicateSubmissionGuardTest.php`:
    - Tests valid 10-char uppercase bKash TxID passes.
    - Tests duplicate bKash TxID matching existing lead throws ValidationException.
    - Tests duplicate bKash TxID matching existing invoice payment_reference throws ValidationException.
    - Tests email uniqueness blocks duplicate application for pending/approved leads.
    - Tests email uniqueness blocks application if member account exists in users table.
    - Tests reapplicant with previously rejected lead is permitted to reapply.
    - Tests blocked lead email is rejected.
    - Tests IP rate limiter blocks excessive submissions (> 10/min).
  </action>
