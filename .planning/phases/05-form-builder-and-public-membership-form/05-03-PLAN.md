    Enhance `PublicMembershipForm.php` and `public-membership-form.blade.php` with Alpine.js and Livewire reactive logic:
    1. Geographic Division & District Cascade (Fields 12 & 13):
       - Division select emits reactive update `wire:model.live="address_division"`.
       - When `address_division` updates in PHP or Alpine:
         - `$available_districts` updates to the exact list of districts belonging to that division per FIELD-DICTIONARY.md Section 4 (e.g. Barishal: 6 districts, Chattogram: 11 districts, Dhaka: 13 districts, Khulna: 10 districts, Mymensingh: 4 districts, Rajshahi: 8 districts, Rangpur: 8 districts, Sylhet: 4 districts).
         - If the current `$address_district` is not in the new allowed list, it is immediately reset to null.
    2. Dynamic Minor Consent Trigger (Fields 6 & 7 per DEC-09):
       - Date of birth input utilizes `wire:model.live.debounce.300ms="date_of_birth"`.
       - Client-side Alpine component monitors DOB changes: computes `age = Math.floor((new Date() - new Date(dob)) / 31557600000)`.
       - When age < 18:
         - Field 7 transitions to visible with an amber warning banner: "Because you are under 18 years old, a signed Parental/Guardian Consent Form is required."
         - Includes downloadable link to official template (`/forms/templates/EMK-Parental-Consent-Form.pdf`).
         - Upload file input becomes required.
       - When age >= 18:
         - Field 7 is hidden, and `$parental_consent_file` is cleared/nullified.
    3. Conditional Occupational and Institutional Inputs:
       - Field 17 (`occupation`): when value equals `'other'`, shows child input `occupation_other` with required flag.
       - Field 19 (`highest_certification`): when value equals `'other'`, shows child input `highest_certification_other` with required flag.
       - Field 21 (`has_us_experience`): when true/1, shows child input `us_experience_location` with required flag.
       - Field 23 (`is_american_alumni`): when true/1, shows child input `american_institution_name` with required flag.
    4. bKash Transaction ID Formatting (Field 30 per DEC-05):
       - Bind input event with Alpine.js transform: `x-on:input="$el.value = $el.value.toUpperCase().replace(/[^A-Z0-9]/g, '').slice(0, 10)"`.
       - Restricts length strictly to 10 characters and auto-capitalizes lowercase letters.
