    - Method `export(Form $form, string $workspaceId, array $filters = []): \Symfony\Component\HttpFoundation\StreamedResponse`:
      1. Enforces workspace scoping: queries `form_submissions` joined with `leads` where `workspace_id = $workspaceId` (unless actor is Superadmin).
      2. Applies search and date filters.
      3. Implements CSV formula injection sanitization: prepends a single quote (`'`) to any cell value beginning with `=`, `+`, `-`, or `@` to neutralize Excel formula execution risks.
      4. Streams CSV rows with headers:
         `Submission UUID, Submitted At, Target Space, Status, First Name, Last Name, Email, Contact Number, Sex, Date of Birth, Age, Has Youth Consent, Division, District, Occupation, Institution, bKash TxID, Terms Agreed`.
      5. Records an immutable audit log entry in `audit_logs` table per DEC-11 (D-11):
         - `workspace_id`: current workspace ID
         - `actor_type`: User class
         - `actor_id`: authenticated user ID
         - `actor_guard`: 'web'
         - `event`: `'form_submissions_exported'`
         - `auditable_type`: Form::class
         - `auditable_id`: $form->id
         - `old_values`: null
         - `new_values`: JSON metadata with filter params, exported row count, and filename
         - `ip_address`: request client IP
         - `user_agent`: request user agent

    Register export route in `routes/web.php` inside the `/crm/{workspace}` route group:
