## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Member Portal → Change Request Table | Member submits proposed modifications; cannot bypass review queue |
| Staff Review Directory → Database Update | Only authorized Workspace Managers can approve state transitions |
| Concurrency Boundary | Concurrent submissions could cause duplicate pending requests or race conditions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-07 | Tampering | MemberChangeRequestService | high | mitigate | Prevent direct member mutations on the members table; force all updates through the member_change_requests queue with explicit field whitelisting. |
| T-09-08 | Race Condition | MemberChangeRequestService | high | mitigate | Enforce database assertions and row-level locks ensuring no duplicate pending requests of the same type can be created simultaneously. |
| T-09-09 | Elevation of Privilege | MemberChangeRequestDirectory | high | mitigate | Restrict change request approval authority strictly to Workspace Managers and Superadmin per DECISION-REGISTER.md. |
