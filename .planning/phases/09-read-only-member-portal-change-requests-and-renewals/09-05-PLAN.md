       - Method `isRenewalWindowOpen(Member $member): bool`:
         - If `$member->status === 'inactive'`, return `true` (expired members may renew at any time).
         - If `$member->status === 'active'`:
           - Compare `$member->expiry_date` with `Carbon::now()`:
           - Return `Carbon::now()->diffInDays($member->expiry_date, false) <= 30`. (If remaining days <= 30, window is open; if > 30, window is closed).
         - If `$member->status === 'revoked'`, return `false` (revoked members cannot renew).
       - Method `submitRenewalRequest(Member $member, int $termId, string $bkashTxid): MemberChangeRequest`:
         - Assert `$this->isRenewalWindowOpen($member)` is true. If false, throw `\DomainException('Renewal window is not open. You can renew starting 30 days prior to your membership expiration.')`.
         - Check no pending renewal request already exists for this member:
           `$pending = MemberChangeRequest::where('member_id', $member->id)->where('request_type', MemberChangeRequest::TYPE_RENEWAL)->where('status', MemberChangeRequest::STATUS_PENDING)->exists();`
           If `$pending`, throw `\DomainException('A renewal request is already pending review for this membership.')`.
         - Term validation: Find active `MembershipTerm` belonging to member's workspace:
           `$term = MembershipTerm::where('id', $termId)->where('workspace_id', $member->workspace_id)->where('is_active', true)->firstOrFail();`
         - bKash Transaction ID validation per DEC-05:
           - Sanitize: `$cleanTxid = strtoupper(trim($bkashTxid));`
           - Regex check: Must match `/^[A-Z0-9]{10}$/`.
           - Uniqueness across leads: `Lead::where('bkash_txid', $cleanTxid)->exists()`.
           - Uniqueness across invoices: `Invoice::where('payment_reference', $cleanTxid)->exists()`.
           - Uniqueness across pending requests: `MemberChangeRequest::where('status', 'pending')->where('new_payload->bkash_txid', $cleanTxid)->exists()`.
           - If any exists, throw `\DomainException('This bKash Transaction ID has already been submitted or verified.')`.
         - Create `MemberChangeRequest`:
           `workspace_id = $member->workspace_id`, `member_id = $member->id`, `request_type = MemberChangeRequest::TYPE_RENEWAL`, `status = MemberChangeRequest::STATUS_PENDING`,
           `old_payload = ['expiry_date' => $member->expiry_date?->toDateString(), 'term_id' => $member->membership_term_id, 'status' => $member->status]`,
           `new_payload = ['term_id' => $term->id, 'term_name' => $term->name, 'duration_months' => $term->duration_months, 'fee_bdt' => $term->fee_bdt, 'bkash_txid' => $cleanTxid]`,
           `justification = "Membership renewal for term: {$term->name}"`.
         - Emit `AuditLog` entry (`event_type = 'member_renewal_submitted'`).
         - Return request.

       - On submit: Calls `MemberRenewalService::submitRenewalRequest`, flashes success toast: "Renewal request submitted. Workspace staff will verify your bKash payment and update your validity.", and closes modal.

       - Add method `approveRenewal(MemberChangeRequest $request, User $reviewerUser, ?string $managerNotes = null): Member`:
         - Verify reviewer has `invoices.verify_payment` or `members.edit` permission or role `['workspace_manager', 'superadmin', 'global_admin']`.
         - Assert `$request->request_type === MemberChangeRequest::TYPE_RENEWAL`.
         - Assert `$request->status === MemberChangeRequest::STATUS_PENDING`.
         - Execute inside `DB::transaction()`:
           - Lock `$request` row, `$member` row, and `$term` row (`lockForUpdate()`).
           - Retrieve `$term = MembershipTerm::findOrFail($request->new_payload['term_id'])`.
           - Retrieve `$bkashTxid = $request->new_payload['bkash_txid']`.
           - Final check: Assert `$bkashTxid` does not exist in `invoices.payment_reference`.
           - --- DYNAMIC EXPIRY MATHEMATICS (STATUS-DICTIONARY.md Section 7.2) ---
           - Let `$today = Carbon::today()`.
           - Let `$currentExpiry = Carbon::parse($member->expiry_date)`.
           - Early Renewal Math:
             - If `$currentExpiry->greaterThanOrEqualTo($today)`:
               - The member is renewing before or on their expiration date.
               - New Expiry Date = Current Expiry Date + Term Duration in Months:
                 `$newExpiry = $currentExpiry->copy()->addMonths((int) $term->duration_months);`
               - Start date remains unchanged.
               - Remaining days are preserved with ZERO loss of valid membership time.
           - Late Renewal Math (Post-Expiration):
             - If `$currentExpiry->lessThan($today)` or `$member->status === 'inactive'`:
               - The membership has already lapsed.
               - New Start Date = Current Approval Date (`$today`).
               - New Expiry Date = Approval Date + Term Duration in Months:
                 `$member->start_date = $today->toDateString();`
                 `$newExpiry = $today->copy()->addMonths((int) $term->duration_months);`
           - Update Member:
             `$member->expiry_date = $newExpiry->toDateString();`
             `$member->membership_term_id = $term->id;`
             `$member->status = 'active';`
             `$member->save();`
           - --- GENERATE POST-RENEWAL PAID INVOICE (DEC-03) ---
           - Generate invoice number: `INV-{YEAR}-{MEMBER_SEQ_5}` with renewal suffix or next sequence:
             `$invoiceNumber = sprintf('INV-%04d-%s-R', $today->year, substr($member->member_id, -5));`
             (If `$invoiceNumber` exists, append incremental suffix e.g. `-R2`).
           - Create Invoice:
             `Invoice::create([`
             `    'invoice_number' => $invoiceNumber,`
             `    'workspace_id' => $member->workspace_id,`
             `    'member_id' => $member->id,`
             `    'lead_id' => $member->lead_id,`
             `    'amount_bdt' => $term->fee_bdt,`
             `    'payment_method' => 'bkash_manual',`
             `    'payment_reference' => $bkashTxid,`
             `    'status' => 'paid',`
             `    'paid_at' => now(),`
             `]);`
           - Transition `member_change_requests`:
             `$request->update(['status' => MemberChangeRequest::STATUS_APPROVED, 'reviewed_by_user_id' => $reviewerUser->id, 'reviewed_at' => now(), 'manager_notes' => $managerNotes]);`
           - Emit immutable `AuditLog` entry (`event_type = 'member_renewal_approved'`):
             `actor_id = $reviewerUser->id`, `actor_guard = 'web'`, `auditable_type = Member::class`, `auditable_id = $member->id`, `workspace_id = $member->workspace_id`,
             `old_values = $request->old_payload`,
             `new_values = array_merge($request->new_payload, ['start_date' => $member->start_date->toDateString(), 'expiry_date' => $member->expiry_date->toDateString(), 'invoice_number' => $invoiceNumber])`.
           - Trigger workflow rule `WorkflowRule::TRIGGER_REQUEST_OUTCOME` ('member.change_request_outcome').
           - Return `$member->fresh()`.
    2. Update `app/Livewire/Members/MemberChangeRequestDirectory.php`:
       - Renewal requests render with a Blue badge: "Membership Renewal".
       - Review modal displays: Selected Term, Fee Amount (BDT), bKash Transaction ID, Current Expiry Date, and Projected New Expiry Date (calculated in real time showing Early vs Late calculation).
       - Clicking Approve calls `MemberRenewalService::approveRenewal`.
    3. Expand `tests/Feature/MemberRenewalWorkflowTest.php`:
       - Early renewal: Member expiring on 2026-12-31 renews for 12 months on 2026-12-05 -> new expiry is 2027-12-31 (exactly 12 months added to previous expiry; 0 days lost).
       - Late renewal: Member expired on 2026-10-01 renews on 2026-11-05 for 12 months -> new start date is 2026-11-05, new expiry is 2027-11-05.
       - Inactive member status automatically restored to 'active'.
       - Paid Invoice record is created with bKash reference and status 'paid'.
       - Immutable audit log records `member_renewal_approved`.
