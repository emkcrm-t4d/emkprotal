  <action>
    Implement authenticated member document streaming with strict IDOR defense per PORT-02, ARCH-06, and DEC-09 (D-09):
    1. Create `app/Http/Controllers/Portal/PortalDocumentDownloadController.php`:
       - Handle route: `GET /portal/documents/{attachment}` where `{attachment}` is the UUID of `LeadAttachment`.
       - Retrieve authenticated user: `$user = Auth::guard('member')->user();` and resolve `$member = $user?->member;`.
       - If no authenticated member, abort HTTP 401.
       - Find attachment: `$attachment = LeadAttachment::withoutGlobalScopes()->where('uuid', $attachmentUuid)->firstOrFail();`.
       - IDOR Verification Guard:
         - Check that the attachment belongs to the member: either `$attachment->lead_id === $member->lead_id` OR the attachment's file path matches the member's storage directory (`workspaces/{$member->workspace_id}/members/{$member->uuid}/` or `workspaces/{$member->workspace_id}/leads/{$member->lead?->uuid}/`).
         - If attachment does NOT belong to the authenticated member, abort with HTTP 403: "Unauthorized document access."
       - Verify file exists on private storage disk: `Storage::disk('private')->exists($attachment->file_path)`. If not, abort 404.
       - Record access event in `audit_logs` table (`event_type = 'portal_document_accessed'`) with `actor_id = $user->id`, `actor_guard = 'member'`, `auditable_type = LeadAttachment::class`, `auditable_id = $attachment->id`, `workspace_id = $member->workspace_id`.
       - Stream response using `Storage::disk('private')->response($attachment->file_path, $attachment->original_filename, ['Content-Disposition' => 'inline', 'Content-Type' => $attachment->mime_type])`.
    2. Register route in `routes/web.php`:
       - Inside `Route::prefix('/portal')->middleware(['auth:member', 'member.password.reset'])`:
         `Route::get('/documents/{attachment}', [PortalDocumentDownloadController::class, 'download'])->name('portal.documents.download');`
    3. Expand `tests/Feature/PortalReadOnlyProfileTest.php`:
       - Member can download their own uploaded identity document and studio photo.
       - Attempting to download an attachment belonging to a different member or lead returns HTTP 403 Forbidden (preventing IDOR).
       - Guest attempting download returns HTTP 401 or redirect to login.
       - Audit log records `portal_document_accessed` with actor guard 'member'.
  </action>
