<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External IMAP Server -> `MailboxSyncService` | Untrusted inbound email headers, sender addresses, and HTML bodies crossing into the CRM database. |
| Staff Browser -> `EmailThreadPanel` | Authenticated workspace staff viewing correspondence threads and dispatching outbound official replies. |
| Environment Config -> `ImapMailboxAdapter` | Sensitive IMAP/SMTP credentials read from server environment configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering / XSS | `MailboxSyncService` / `EmailThreadPanel` | High | mitigate | Strip `<script>`, `<iframe>`, `<object>`, `<embed>`, and inline `on*` event attributes on inbound HTML ingestion, and render message bodies using safe text / escaped output in Blade views. |
| T-08-02 | Information Disclosure | `EmailThreadPanel` / `EmailThread` | High | mitigate | Enforce `BelongsToTenant` global scope, `ValidatesWorkspaceOnHydration`, and explicit workspace match checks on `Lead`/`Member` and `EmailThread` records; reject cross-workspace access with HTTP 403 per DEC-01. |
| T-08-03 | Information Disclosure | `ImapMailboxAdapter` / `AuditLog` | High | mitigate | Load IMAP/SMTP credentials strictly from environment/config (`config('mail.imap')`), never store mailbox passwords in database tables or expose them in exception messages or `audit_logs` per DEC-11. |
| T-08-SC | Tampering | npm/pip/cargo/composer installs | High | mitigate | Package-legitimacy gate + zero new unvetted external composer dependencies required (uses native PHP/Laravel mail & socket adapters). |
</threat_model>
