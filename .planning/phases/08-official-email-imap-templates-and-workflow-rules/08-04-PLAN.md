    1. Create `app/Domain/Mail/Models/WorkflowRule.php`:

       - Define static allowlisted trigger constants (strictly bounded, zero-eval per DEC-02):
         - `TRIGGER_LEAD_SUBMITTED = 'lead.submitted'`
         - `TRIGGER_LEAD_MISSING_ITEMS = 'lead.missing_items'`
         - `TRIGGER_LEAD_REJECTED = 'lead.rejected'`
         - `TRIGGER_LEAD_CONVERTED = 'lead.converted'`
         - `TRIGGER_PORTAL_ACTIVATED = 'member.portal_activated'`
         - `TRIGGER_ID_CARD_READY = 'id_card.ready_for_pickup'`
         - `TRIGGER_RENEWAL_WINDOW_OPEN = 'member.renewal_window_open'`
         - `TRIGGER_MEMBER_EXPIRED = 'member.expired'`
         - `TRIGGER_REQUEST_OUTCOME = 'member.change_request_outcome'`
       - Define `ALLOWED_TRIGGERS` array containing those 9 canonical trigger events.
       - Relationship `template()`: `belongsTo(EmailTemplate::class, 'email_template_id')`.
       - Cast `is_enabled` to `'boolean'`, `days_offset` to `'integer'`, `conditions` to `'array'`.
    2. Create `database/seeders/WorkflowRuleSeeder.php` and register it in `database/seeders/DatabaseSeeder.php`:
       - Ensure `EmailTemplateSeeder` has run for the workspace, then seed all 9 default workflow rules per workspace linking each `trigger_event` to its corresponding `EmailTemplate` (`days_offset = 30` for `member.renewal_window_open`, `0` for all others, `is_enabled = true`).
    3. Create `app/Domain/Mail/Services/WorkflowRuleEngine.php`:
       - Method `trigger(string $workspaceId, string $triggerEvent, string $recipientEmail, array $variables = [], ?int $leadId = null, ?int $memberId = null, ?string $entityKey = null): ?EmailMessage`:
         - Assert `$triggerEvent` is in `WorkflowRule::ALLOWED_TRIGGERS`; throw `\InvalidArgumentException` if an unknown trigger is passed.
         - Query `WorkflowRule::withoutGlobalScopes()->with('template')->where('workspace_id', $workspaceId)->where('trigger_event', $triggerEvent)->where('is_enabled', true)->first()`.
         - If no enabled rule or linked active `EmailTemplate` exists, return `null`.
         - Evaluate optional bounded declarative `$rule->conditions` (e.g., `['require_status' => ...]` checked via strict array key equality — never `eval()`).
         - Dispatch via `QueuedEmailDispatcher::dispatchTemplate($workspaceId, $rule->template->template_key, $recipientEmail, $variables, $leadId, $memberId, $entityKey ?? "{$triggerEvent}:" . ($memberId ?? $leadId ?? $recipientEmail))`.
       - Method `processWorkspaceMembershipMilestones(string $workspaceId, ?\Carbon\Carbon $referenceDate = null): array` returning `['renewal_notices_queued' => int, 'expired_transitions' => int]`:
         - Use `$today = ($referenceDate ?? now())->copy()->startOfDay()`.
         - Look up the workspace's `member.renewal_window_open` rule (seed defaults if missing). If `is_enabled`, let `$daysOffset = max(1, (int) ($renewalRule->days_offset ?: 30))` and `$windowEnd = $today->copy()->addDays($daysOffset)`.
         - Find all `Member::withoutGlobalScopes()->where('workspace_id', $workspaceId)->where('status', 'active')->whereDate('expiry_date', '>=', $today->toDateString())->whereDate('expiry_date', '<=', $windowEnd->toDateString())->get()`.
         - For each member in the renewal window, call `$this->trigger($workspaceId, WorkflowRule::TRIGGER_RENEWAL_WINDOW_OPEN, $member->email, ['member_name' => $member->full_name, 'member_id' => $member->member_id, 'expiry_date' => $member->expiry_date->format('Y-m-d'), 'workspace_name' => $workspaceId], $member->lead_id, $member->id, "renewal_window:{$member->id}:{$member->expiry_date->format('Y-m-d')}")`. Because `entityKey` includes the member's `expiry_date`, `QueuedEmailDispatcher` guarantees the renewal notice is sent at most once per term expiry cycle!
         - Find all expired active members: `Member::withoutGlobalScopes()->where('workspace_id', $workspaceId)->where('status', 'active')->whereDate('expiry_date', '<', $today->toDateString())->get()`.
         - For each expired member: transition `$member->status = 'inactive'`, save `$member`, write an immutable `AuditLog` (`event_type = AuditLog::EVENT_MEMBER_STATUS_CHANGED`, `old_values = ['status' => 'active']`, `new_values = ['status' => 'inactive', 'expiry_date' => $member->expiry_date->format('Y-m-d')]`, `reason = 'Automated membership expiration milestone transition.'`), and call `$this->trigger($workspaceId, WorkflowRule::TRIGGER_MEMBER_EXPIRED, $member->email, [...], $member->lead_id, $member->id, "expired:{$member->id}:{$member->expiry_date->format('Y-m-d')}")`.
    4. Create `app/Console/Commands/ProcessMembershipMilestonesCommand.php`:
       - Signature: `crm:process-membership-milestones {--workspace= : Optional workspace ID}`.
       - Runs `WorkflowRuleEngine::processWorkspaceMembershipMilestones` across active workspaces (or `--workspace`) and registers daily schedule in `routes/console.php` (`Schedule::command('crm:process-membership-milestones')->dailyAt('01:00')`).
    5. Create feature test `tests/Feature/WorkflowRuleEngineTest.php`:
       - Verify `WorkflowRuleEngine::trigger` queues an `EmailMessage` when the rule is enabled and returns `null` when the rule is disabled (`is_enabled = false`).
       - Verify `crm:process-membership-milestones` queues a renewal window notification for an active member expiring in 25 days (within the 30-day window) and does not double-send when run a second time on the same day.
       - Verify `crm:process-membership-milestones` transitions an active member whose `expiry_date` was yesterday to `'inactive'`, writes a `member_status_changed` audit log, and queues the `membership_expiry` email.
