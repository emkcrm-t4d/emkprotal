| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Elevation of Privilege / RCE (SSTI) | `EmailTemplateRenderer` | Critical | mitigate | Strictly prohibit `eval()` or dynamic Blade compilation on database templates per DEC-02; interpolate only allowlisted `{{placeholder}}` tokens via deterministic `strtr` string replacement. |
| T-08-05 | Tampering / Stored XSS | `EmailTemplateManager` / `EmailTemplateRenderer` | High | mitigate | Strip `<script>` tags on template save and HTML-escape all variable values (`htmlspecialchars`) during rendering. |
