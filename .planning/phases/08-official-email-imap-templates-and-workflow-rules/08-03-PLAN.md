       - Method `dispatchTemplate(string $workspaceId, string $templateKey, string $recipientEmail, array $variables = [], ?int $leadId = null, ?int $memberId = null, ?string $entityKey = null, string $locale = 'bilingual', ?int $actorId = null): EmailMessage`:
         - Compute `$deduplicationKey = $this->buildDeduplicationKey($workspaceId, $templateKey, strtolower(trim($recipientEmail)), $entityKey ?? ($memberId ? "member:{$memberId}" : ($leadId ? "lead:{$leadId}" : 'general')))`.
         - Idempotent deduplication check: query `EmailMessage::withoutGlobalScopes()->where('deduplication_key', $deduplicationKey)->first()`. If an existing message is found in status `'sent'` or `'queued'`, return that existing `EmailMessage` immediately without creating a duplicate row or dispatching a second Horizon job!
         - Resolve active `EmailTemplate` for `$workspaceId` and `$templateKey` (if none exists yet, seed workspace templates via `EmailTemplateSeeder` or fallback gracefully).
         - Render subject, HTML body, and text body via `EmailTemplateRenderer::render($template, $variables, $locale)`.
         - Resolve or create an `EmailThread` in `$workspaceId` for `$recipientEmail` (linking `$leadId` and `$memberId`).

Str::uuid() . '@emkcenter.org>'`, and `sent_by_user_id = $actorId`.
         - Dispatch `DispatchOfficialEmailJob::dispatch($message->id)` onto the Horizon queue.
         - Return `$message`.

         - Redact any password, secret, token, API key, or URI credentials matching patterns like `/(password|secret|token|key|auth|pass)\s*[:=]\s*\S+/i` or `/:\/\/[^:\s]+:([^@\s]+)@/i` with `[REDACTED]` so raw SMTP/IMAP secrets never leak into `email_messages.failure_reason` or `audit_logs`.
    3. Create `app/Jobs/DispatchOfficialEmailJob.php`:
       - Implements `ShouldQueue`, `ShouldBeUnique`.
       - Configure `$tries = 3`, `$backoff = [30, 120, 300]`, `$uniqueFor = 300`, and `uniqueId(): string` returning `'email-msg-' . $this->emailMessageId`.
       - In `handle(QueuedEmailDispatcher $dispatcher)`:
         - Within a database transaction with `lockForUpdate()`, load `EmailMessage::withoutGlobalScopes()->lockForUpdate()->find($this->emailMessageId)`.
         - Guard: if `!$message` or `$message->status === 'sent'`, return immediately (idempotent retry guard preventing duplicate sends on Horizon worker retry).
         - Send `TemplatedLifecycleMail` via `Mail::to($message->to_email)->send(...)`.
         - Update `$message` (`status = 'sent'`, `sent_at = now()`, `failure_reason = null`), update parent `EmailThread` (`last_message_at = now()`), and create an immutable `AuditLog` (`event_type = AuditLog::EVENT_OFFICIAL_EMAIL_DISPATCHED`, `workspace_id = $message->workspace_id`, `auditable_type = EmailMessage::class`, `auditable_id = $message->id`, `new_values = ['to_email' => $message->to_email, 'template_key' => $message->template_key, 'deduplication_key' => $message->deduplication_key, 'status' => 'sent']`).
         - Catch `\Throwable $e`: sanitize error via `$dispatcher->sanitizeFailureMessage($e->getMessage())`, update `$message` (`status = 'failed'`, `failure_reason = $sanitized`), record `AuditLog` (`event_type = AuditLog::EVENT_OFFICIAL_EMAIL_FAILED`, `new_values = ['to_email' => $message->to_email, 'template_key' => $message->template_key, 'failure_reason' => $sanitized]`), and rethrow `$e` so Horizon tracks the retry/failure.
