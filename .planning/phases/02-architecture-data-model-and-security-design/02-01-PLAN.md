| Boundary | Description |
|----------|-------------|
| Client -> Application Layer | Untrusted input from public applicant or staff crosses web routes and Livewire component endpoints |
| Monolith Core -> Module Boundary | Module invocation must match registered declared actions and prevent dynamic runtime evaluation |
| Application Layer -> Relational Store | Queries must adhere to strict foreign keys, unique constraints, and append-only audit rules |
