    Document:
    1. Threat Model & Defense-in-Depth Principle: Tenancy isolation must never rely on client parameters or a single filter. Tenancy defense is enforced across four independent server-side barriers.
    2. Layer 1: Route Middleware (VerifyWorkspaceAccess):
       - Inspects {workspace} route parameter on all CRM and administrative routes (e.g. /crm/{workspace}/leads).
       - Validates that non-Superadmin and non-GlobalAdmin users possess auth()->user()->workspace_id identical to the requested route parameter.
       - Aborts immediately with HTTP 403 (Unauthorized workspace access) on any mismatch.
    3. Layer 2: Livewire Hydration Guard (ValidatesWorkspaceOnHydration trait):
       - Defends against parameter tampering where a user modifies public component properties (e.g. $leadId, $memberId) in network payloads.
       - Re-evaluates workspace ownership during Livewire component hydration on every request before executing any action method, aborting with HTTP 403 on tenant violation.
    4. Layer 3: Eloquent Global Scope (TenantScope):
       - Automatically applies WHERE workspace_id = auth()->user()->workspace_id to all SELECT, UPDATE, and DELETE queries on tenant-owned models (leads, members, invoices, id_cards, membership_terms).
       - Bypasses scope only for superadmin and global_admin roles.
       - Hard Rule: Strictly forbid withoutGlobalScope() in all controllers, Livewire components, and reports; reserve exclusively for root Superadmin console commands.
    5. Layer 4: Storage Namespacing & Streaming Controller:
       - Applicant documents and photos stored in private disk: storage/app/private/workspaces/{workspace_id}/....
       - Direct web symlinks strictly prohibited.
       - Streaming guarded by DocumentDownloadController asserting user workspace ownership and Spatie permissions before serving file streams.
    6. Staging Pool Architecture: Define handling for non-EMK submissions where workspace_id is NULL (routed to Superadmin staging pool until future workspaces are provisioned).
  </action>
