| Boundary | Description |
|----------|-------------|
| Untrusted User Input -> Module Registry Resolution | Request parameters attempting to execute arbitrary code or call unvetted actions |
| Workspace Tenancy Context -> Disabled Module Routes | Requests attempting to invoke features or routes that are disabled for the tenant |
| Admin Shell UI -> Staff Authentication & Role State | Client-side UI rendering must not leak privileged cross-workspace navigation to standard staff |
