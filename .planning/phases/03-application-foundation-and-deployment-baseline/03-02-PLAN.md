## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | MySQL Relational Store (leads table) | high | mitigate | Enforce unique constraint uq_leads_bkash_txid on 10-character uppercase bKash TxID; reject duplicate submissions at the database tier per DEC-05. |
| T-03-05 | Repudiation | MySQL Relational Store (audit_logs table) | critical | mitigate | Enforce MySQL 8.4 engine triggers (trg_audit_logs_prevent_update, trg_audit_logs_prevent_delete) signaling SQLSTATE 45000 on any UPDATE or DELETE attempt per DEC-11. |
| T-03-06 | Information Disclosure | MySQL Relational Store (workspaces & users) | high | mitigate | Enforce foreign key constraints with RESTRICT delete rules and composite workspace indices to prevent tenant data leakage per DEC-01. |
| T-03-SC | Tampering | npm/composer installs | high | mitigate | Package-legitimacy audit verified; use verified composer and npm packages only. |
</threat_model>
