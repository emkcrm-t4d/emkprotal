    1. Lock acquisition order to eliminate deadlocks:
       - Lock 1: `member_id_sequences` row via `sequenceGenerator->nextMemberId($spaceCode, $year)`
       - Lock 2: `leads` row via `Lead::where('id', $lead->id)->lockForUpdate()->firstOrFail()`
       - Lock 3: `membership_terms` row via `MembershipTerm::where('id', $termId)->lockForUpdate()->firstOrFail()`
    2. Step 1 (Invariant Assertion):
       - Asserts `payment_verification_status === 'verified'`
       - Asserts `document_verification_status === 'verified'`
       - Asserts `photo_verification_status === 'verified'`
       - Asserts `status === 'approved'`
       - Asserts if `age_at_submission < 18`: `has_parental_consent === true` per DEC-09
       - Asserts `Member::where('email', $lead->email)->whereIn('status', ['active', 'inactive', 'restricted'])->doesntExist()`
       - If any fails, throws `UnmetConversionInvariantException`
    3. Step 2: Allocate Member ID (`$memberId`)
    4. Step 3 & 4: Calculate Dynamic Dates (DEC-08) & Create Member:
       - `start_date` = current timestamp (`Carbon::now()`)
       - `expiry_date` = `start_date->copy()->addMonths($term->duration_months)`

       - Create `Member` record copying all 31 verified applicant fields

    6. Step 6: Generate Post-Conversion Paid Invoice (DEC-03):
       - `invoice_number = sprintf('INV-%04d-%s', $year, substr($memberId, -5))`
       - `amount_bdt = $term->fee_bdt`, `payment_method = 'bkash_manual'`, `payment_reference = $lead->bkash_txid`, `status = 'paid'`, `paid_at = now()`
    7. Step 7: Create ID Card Record:
       - `card_number = $memberId`, `status = 'provided_for_printing'`
    8. Step 8: Update Lead Status:
       - `status = 'converted'`, `converted_member_id = $member->id`

    10. Step 10: Emit Immutable Audit Log Entry (DEC-11):
