## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staff User -> Audit Log Viewer | Staff could attempt to view audit logs without proper authorization or view logs belonging to other offices |
| Permission Mutation -> Session State | Delayed cache clearing could allow revoked staff to execute unauthorized actions before cache TTL expires |
| Database Client -> Forensic History | An attacker could attempt to delete or alter audit log entries to cover tracks |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-13 | Information Disclosure | Audit Log Viewer Interface | high | mitigate | Restrict AuditLogViewer with platform_services.view_audit_logs permission and enforce workspace scoping so Managers see only their workspace logs per DEC-01 and DEC-11. |
| T-04-14 | Elevation of Privilege | Spatie Permission Cache | high | mitigate | Trigger InvalidatePermissionCacheListener on every role or permission mutation, purging cache immediately so revocations take immediate effect per AUTH-05. |
| T-04-15 | Repudiation | Forensic Audit Records | critical | mitigate | MySQL native triggers prevent UPDATE and DELETE with SQLSTATE 45000; test suite continuously validates trigger immutability per DEC-11. |
| T-04-SC | Tampering | npm/composer installs | high | mitigate | Package-legitimacy gate: native Livewire and Spatie components verified; lockfiles committed. |
