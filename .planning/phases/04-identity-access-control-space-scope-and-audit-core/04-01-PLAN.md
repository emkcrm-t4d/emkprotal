<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Web Application | Unauthenticated or cross-guard requests attempt to access administrative staff endpoints |
| Staff Web Session -> Member Portal Session | Staff session cookies could collide or leak into member session cookies without strict guard separation |
| User Credential Boundary -> Password Reset | Converted members or new staff logging in with temporary default credentials could access records before setting a secret password |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | Multi-Guard Authentication (config/auth.php) | high | mitigate | Enforce multi-guard separation (web vs member) with independent session cookies (emk_web_session vs emk_member_session) per DEC-06. Reject cross-guard credentials. |
| T-04-02 | Elevation of Privilege | Spatie RBAC Role Hierarchy | high | mitigate | Seed canonical roles from ModuleRegistry with explicit permission bindings. Verify authorization checks reject unauthorized role actions server-side. |
| T-04-03 | Elevation of Privilege | First-Login Password Reset (EnsurePasswordReset) | high | mitigate | Intercept all requests for users with must_reset_password = true via EnsurePasswordReset middleware, blocking access to CRM records until password reset completes per DEC-06. |
| T-04-SC | Tampering | npm/composer installs | high | mitigate | Package-legitimacy gate: spatie/laravel-permission locked in composer.lock; no dynamic external package downloads. |
</threat_model>
