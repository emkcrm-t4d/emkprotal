<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Workspace Manager -> Role Assignment API | Workspace Manager could attempt to assign non-delegable permissions (e.g. reversal, approval) to staff |
| Workspace Manager -> Staff User Target | Workspace Manager in one workspace could attempt to assign roles or permissions to staff in another workspace |
| Permission Mutation -> Runtime Execution | Cached permissions in Redis/memory could persist after revocation, allowing unauthorized actions mid-session |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-07 | Elevation of Privilege | RBAC Delegation Service (DelegationPolicyService) | high | mitigate | Hardcode 16 strictly non-delegable actions in immutable allowlist; throw UnauthorizedDelegationException if Manager attempts to delegate non-delegable actions per T-01-07. |
| T-04-08 | Elevation of Privilege | Cross-Workspace Staff Assignment | high | mitigate | Assert $manager->workspace_id === $targetStaff->workspace_id in assertCanDelegate; throw TenancyBoundaryException on boundary breach per DEC-01. |
| T-04-09 | Elevation of Privilege | Permission Cache Persistence | high | mitigate | Invoke app(PermissionRegistrar::class)->forgetCachedPermissions() on every role or permission mutation to force immediate cache eviction per AUTH-05. |
| T-04-SC | Tampering | npm/composer installs | high | mitigate | Package-legitimacy gate: spatie/laravel-permission locked; no third-party plugin loaders permitted. |
</threat_model>
